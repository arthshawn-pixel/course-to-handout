# 网课转讲义 v0.4.0（公开测试版）

以 B 站课程链接为主要输入，配合字幕和关键板书，将理工及经管类网课整理为保留推导、带来源定位的 A4 单栏 PDF 讲义。也支持本地视频、字幕和截图。

本版保留随包中文/数学字体、常用跨学科符号、内容核验记录和断点恢复；新增百度网盘的宿主浏览器/官方客户端下载交接，以及本地视频接收、监控与校验。

百度网盘为实验性功能：真实环境中已验证分享页访问及提取码提交，但完整视频下载尚未跑通。测试遇到浏览器控制连接中断和客户端控制授权超时；可能涉及本人的浏览器、网络或宿主工具配置，具体原因尚未确定。登录、扫码和验证码仍由用户自行完成。

88 项 Python、8 项字幕 JS 测试与 Skill 结构校验通过；本地自制媒体测试通过。这些结果不替代真实网盘下载、各宿主客户端或课程专业内容的端到端验收。

- `course-to-handout-source-0.4.0.zip`：通用 Skill 源码、字体、文档、测试及开发工具。
