# Course to Handout · 网课转讲义

**以 B 站课程链接为主要输入，把视频、字幕和关键板书整理成保留推导、带来源定位的 PDF 讲义。**

这是一个通用 Agent Skill，配套 Python 工具链、字体和排版模板。由宿主 AI Agent 阅读材料、理解板书、整理内容，脚本负责素材处理、结构校验、断点和排版。适合将长网课整理为便于自学、复习和打印的讲义。

当前版本：**v0.4.0**。主要面向理工与经管类课程，例如数学、物理、化学、工程、经济、金融和管理。

## 可以做什么

- **从 B 站课程链接开始**：按视频及分 P 建立任务，尝试获取视频和平台逐字字幕；需要时交接宿主浏览器或导入已有字幕。
- **支持本地素材**：可以使用本地视频、SRT/VTT 字幕和带时间戳的截图。平台字幕无法取得时，可导入宿主转写工具的输出。
- **保留教学过程**：围绕概念、定理、例题和练习整理，保留题干、条件、关键推导和结论；结合字幕与关键帧核对板书。
- **保留来源定位**：记录单元对应的视频时间、分 P 和截图来源，导出来源索引及独立处理报告。
- **兼容常用学科记号**：随包提供中文和数学字体，支持常见微积分、线代、物理、化学、工程及金融记号；支持化学式与数值单位块。
- **导出 A4 单栏 PDF**：提供阅读、留白练习两种模式，支持断点恢复和复用已有材料。
- **实验性百度网盘交接**：设计了宿主浏览器/官方客户端下载、用户自行登录、本地视频接收和校验的流程。实际下载尚待端到端验收，见下文。

## 输入与验证状态

| 输入 | 定位与限制 |
|---|---|
| B 站视频链接 | 主要入口；一次任务对应一个视频/分 P。能否获取视频及字幕取决于网站、访问权限与宿主工具能力。 |
| 本地视频、字幕、截图 | 可直接进入素材整理流程；本地工具链和自制样本已有测试记录。 |
| 百度网盘分享链接 | 实验性流程适配；分享页访问和提取码验证已有进展，完整视频下载尚未验收通过。 |

平台 AI 总结不能替代逐字字幕。登录、扫码和验证码由用户亲自操作。Skill 本身不捆绑浏览器、ASR/OCR 模型，也不会自动取得宿主没有提供的能力。

## 怎么使用

安装后向支持该 Skill 的 Agent 描述需求，例如：

> 把这个 B 站课程视频整理成用于自学的 A4 单栏(若喜欢更紧凑排版，可要求按照双栏排版格式输出)讲义，保留完整题干、推导和关键板书，并注明来源时间。链接：……，分 P：……。需要登录时让我自己操作。

Agent 按 [SKILL.md](SKILL.md) 推进素材获取、字幕/截图、单元整理、核验和导出。专业内容仍需复核；现有自动精确枚举只覆盖已经实现的概率模型，其他学科的证明和推导按协议由宿主实际核对。

当前工具链不需要另配云模型 API key，使用宿主已有模型。首次环境准备、浏览器能力及材料获取仍须按实际环境检查。

实测下来，DeepSeek V4.1 flash处理一个四十分钟左右的网课需用时25-40分钟左右，首次运行可能时间稍长

## 安装到 Agent

复制完整的 `course-to-handout` 文件夹，保留 `scripts`、`references`、`templates`、`assets` 等资源。

| 宿主 | 项目内安装方式 |
|---|---|
| Codex | 放入项目的 `.agents/skills/course-to-handout/` |
| Claude Code | 放入项目的 `.claude/skills/course-to-handout/` |
| WorkBuddy | 使用 Release 中的 `course-to-handout-workbuddy-0.4.0.zip` 上传包 |

仓库右侧的 **Releases** 提供 WorkBuddy 上传包和通用源码包。

Windows x64 提供 `scripts/setup_windows.ps1` 准备独立运行环境。Python 3.10+，视频处理使用 FFmpeg；PDF 排版使用 Tectonic 或 XeLaTeX。首次配置请读 [运行说明](references/runtime.md)，不要在每节课重复安装。课程任务与运行缓存使用仓库外的独立目录。

## 百度网盘：实验性功能

设计路径为：分享链接及提取码 → 宿主操作官方网页/客户端 → 用户自行完成登录和验证 → 官方下载 → 校验本地视频 → 按需求停止或继续整理讲义。

任务入口、状态记录、下载目录监控、文件大小检查、视频轨/时长探测、首帧解码和 SHA256 校验已经实现，自制视频的本地接收测试通过。详细操作见 [百度浏览器流程](references/baidu-browser.md)。

**真实网盘视频下载尚未验收通过。** 在开发者本人的测试环境中，已能通过 Chrome 打开官方分享页并提交提取码；随后遇到页面控制连接中断，以及官方客户端控制授权超时。尚未取得完整视频，因而不能宣称下载链路已经跑通。

问题可能与本人使用的浏览器、宿主工具连接、授权或网络配置有关，具体原因尚未定位。目前将其保留为实验性功能，欢迎在其他环境复现和反馈；不能据此保证换一台电脑即可使用。

## 测试与边界

v0.4.0 的记录包括 **88 项 Python 测试、8 项字幕 JavaScript 测试**及 Skill 结构校验通过。自制视频用于本地工具链测试；模拟浏览器观察用于状态流程测试。它们不等于真实课程整理质量或真实网盘下载的端到端验收。

此前已编译和检查两套数学字体的学科符号小样。常用符号支持不等于覆盖所有 Unicode 字符；专业推导、量纲、守恒、金融假设与数值结果仍需按学科复核。
